## 0. 全局骨架与共用规则

### 0.1 画布

- 基准 **1280×800**；**最小宽度 1024**，低于 1024 不提供降级布局（PC only）。
- 三栏：左树 240（折叠 48）／中区自适应（最小 560）／右抽屉 360（最多并列 2 个，合计 ≤480）。
- 顶栏 56 + 可选状态条 32；底部状态条 24（仅编辑器）。
- 行高：列表 40、树节点 32；正文行宽 ≤760。

### 0.2 全局壳（所有登录后页面共用）

```
+----------------------------------------------------------------------------------------------+
| [云笺]   [🔍 搜索笔记、标签…                    ]      [任务 ②]  [中|EN|日]  [☾]  [头像 ▾] |
+----------------------------------------------------------------------------------------------+
| (会话到期横幅 / 断网条 / 异步 job 状态条 —— 三选一或上下叠放，各占 32px，最多 64px)          |
+--------------------+-------------------------------------------------------------------------+
| 左树 240           | 中区（页面主体，最小 560）                            | 右抽屉 360     |
| 我的笔记 / 共享给我 |                                                      | 版本/图片/属性 |
| 回收站 / 标签       |                                                      |               |
+--------------------+-------------------------------------------------------------------------+
```

| 区域 | 组件 | 数据来源 | 交互 |
|---|---|---|---|
| 顶栏左 | 产品名、折叠按钮 | — | 折叠后左树变 48px 图标条 |
| 顶栏中 | 全局搜索框（Enter 提交） | — | 跳 `?q=` 视图，搜索 20/页、512KB 上限 |
| 顶栏右 | 任务入口（badge=运行中数量）、语言、主题、账号菜单 | `jobs`、`profile` | 任务入口开 W-15 面板；语言即时生效 |
| 状态条区 | 到期横幅 / 断网条 / job 条 | `exp`、`navigator.onLine`、`jobs` | 见 W-15；到期横幅无「续期」 |
| 左树 | 我的笔记树、共享给我、回收站、标签 | `index`、`_share_inbox` | 右键/行内菜单：新建、重命名、移动、共享、导出、删除；回收站节点显示未清理条数 |

### 0.3 状态词表（全站统一命名，前端状态机直接用）

| 状态 | 含义 | 通用表现 |
|---|---|---|
| `idle` | 有数据、可操作 | 正常渲染 |
| `loading` | 首次加载/切目录 | 骨架屏，不用全屏 spinner |
| `refreshing` | 有数据时的静默刷新 | 保留旧数据 + 顶部 2px 进度 |
| `empty` | 结果为 0 且非筛选 | 插图 + 引导 + 主操作 |
| `empty_filtered` | 筛选/搜索后为 0 | 「没有匹配结果」+ 清除条件 |
| `paginated` | 分页中 | 底部分页器固定，翻页保滚动位置 |
| `unauthorized` | 401 | 跳登录，带 `next` |
| `forbidden` | 403 无权限 | 页内错误态 |
| `revoked` | 403 `SHARE_REVOKED` | 编辑器只读 + 另存为，不是错误页 |
| `conflict` | 412 | 冲突面板 |
| `job_running` | 409 `JOB_RUNNING` | 子树写操作禁用 + 进度说明 |
| `selected` | 回收站多选态 | 工具条计数 + 批量删除可用 |
| `purging` | 彻底删除 job 进行中 | 目标行/节点「删除中…」+ 任务红点 |
| `partial` | 批量操作部分成功 | 成功项移除、失败项标红可重试 |
| `offline` | 断网 | 只读 + 草稿提示，动作明确失败 |
| `expired` | Token 到期 | 跳登录（草稿已落本地） |
| `lang_switching` | 切换语言瞬间 | 文案重渲染，状态与滚动位置不变 |

### 0.4 错误信封与文案

- 后端只回 `{code, params, data?}`；前端 key 由 `error_codes.py` 生成 `errors.code.<code 小写蛇形>`，禁止手写（9.4、T-A）。
- 原型阶段码值为示意，**不得自造语义**：看到未知 code 一律走 `errors.unknown` + 原码。

| code | HTTP | 用户看到 | 可重试 | 去向 |
|---|---|---|---|---|
| `AUTH_INVALID_CREDENTIALS` | 400 | 用户名或密码不正确 | 是 | 留在登录 |
| `USER_DISABLED` | 400 | 账号已被禁用，请联系管理员 | 否 | 留在登录 |
| `AUTH_TOKEN_EXPIRED` | 401 | （不提示） | 重登 | `/login?next=` |
| `SHARE_FORBIDDEN` | 403 | 你没有访问权限 | 否 | 返回列表 |
| `SHARE_REVOKED` | 403 | 共享已被撤销，你的内容还在 | 另存 | 编辑器只读 |
| `NOTE_NOT_FOUND` | 404 | 笔记不存在或已删除 | 否 | 返回列表 |
| `NOTE_CONFLICT` | 412 | 这篇笔记被别人更新了 | 三选一 | 冲突面板 |
| `DELETE_CONFLICT` | 409 | 内容已变化，请刷新后重试 | 是 | 删除弹层 |
| `JOB_RUNNING` | 409 | 目录正在搬移（n/m） | 等 | 禁用写操作 |
| `ASSET_TOO_LARGE` | 400 | 图片超过 10MB | 换图 | 图片面板 |
| `NOTE_VISIBILITY_FORBIDDEN` | 400 | 管理员已禁止公开笔记 | 否 | 笔记菜单（禁用态）/ W-04a |
| `PUBLIC_NOTE_NOT_FOUND` | 404 | 这个链接已失效 | 否 | `/p/{token}` 匿名页 |
| `USER_NOT_FOUND` | 400 | 未找到该成员 | 是 | 共享弹层 |
| `NETWORK_OFFLINE` | 前端判定 | 网络已断开，内容仍在本地草稿 | 恢复后 | 断网条 |
| `INTERNAL_ERROR` | 500 | 服务出错了 | 是 | 页内错误态 |

### 0.5 字段词典（页面只引用这些概念）

| 来源 | 字段 | 用在哪 |
|---|---|---|
| Frontmatter | `note_id` `title` `slug` `category` `tags` `lang` `visibility` `public_token` `created_at` `updated_at` `version` | 编辑器、属性面板、冲突基线、版本、公开状态徽标 |
| `index.parquet` | `category_path` `file_size` `is_deleted` `deleted_at` `own_share` | 列表列、回收站天数、共享徽标 |

| `_share_inbox.parquet` | `grantee` `share_id` `owner_uuid` `target_type` `target_note_id` `target_dir` `level` `updated_at` | 共享给我（唯一数据源） |
| `profile.json` | `ui_lang` `tz` `theme` `editor_mode` `list_sort` `page_size` | 设置、列表默认 |

| `public_tokens/{token}.json` | `note_id` `created_at` | 公开链接生成/收回 |

## W-01 登录页（P-01）

- **目标用户**：未登录、被登出
- **入口**：`/`、`/login`、401 回跳
- **出口**：`/notes`（或 `next`）；challenge → W-02

```
+----------------------------------------------------------------------+
| [云笺]                                             [中|EN|日] [☾]  |
|                                                                      |
|                  +----------------------------------+                |
|                  | 登录云笺                         |                |
|                  | 用户名 [______________________]   |                |
|                  | 密码   [______________________]👁 |                |
|                  | [          登 录             ]   |                |
|                  | ──────────────────────────────── |                |
|                  | 忘记密码？请联系管理员重置        |                |
|                  +----------------------------------+                |
+----------------------------------------------------------------------+
最小宽度 1024；卡片 400，垂直居中；无营销位、无第三方登录
```

### 区域与组件

| 区域 | 组件 | 数据来源 | 说明 |
|---|---|---|---|
| 页头 | 产品名、语言、主题 | localStorage（未登录） | 登录页也三语 |
| 表单 | 用户名、密码、可见性、提交 | Cognito SRP | 密码不明文出网 |
| 辅助 | 「忘记密码请联系管理员」 | — | 本期无自助找回 |
| 反馈 | 行内错误条 | 错误码表 | 不用 toast |

### 数据字段

| 字段 | 显/编 | 来源 | 空值显示 | 三语风险 |
|---|---|---|---|---|
| 用户名 | 编辑 | 用户输入 | placeholder「用户名」 | 低 |
| 密码 | 编辑 | 用户输入 | placeholder「密码」 | 低 |
| 错误文案 | 显示 | `params` | 隐藏 | 中：日文长 1.4 倍，允许两行 |
| 语言 | 编辑 | localStorage | `zh-CN` | — |

### 操作

| 操作 | 触发 | 前置 | 成功后 | 失败后 |
|---|---|---|---|---|
| 登录 | 按钮/Enter | 两字段非空 | 跳 `next` 或 `/notes` | 行内错误，密码清空，焦点回密码 |
| 切语言 | 点语言 | — | 文案即时重渲染，无刷新 | — |
| 切主题 | 点主题 | — | 存 localStorage，登录后写 profile | — |
| 联系管理员 | 点文字 | — | 展示管理员联系方式（静态） | — |

### 状态机

| 状态 | 页面显示 | 用户可做 |
|---|---|---|
| `idle` | 空表单，登录可点 | 输入、切换语言主题 |
| `loading` | 按钮 loading、输入禁用 | 等待 |
| 密码错 | 行内「用户名或密码不正确」 | 重输 |
| 禁用 | 行内「账号已被禁用」 | 联系管理员 |
| 网络错 | 「网络异常，请检查连接」 | 重试 |
| 已登录 | 不渲染，replace `/notes` | — |

### 错误码

| code | key | 可重试 | 跳转 |
|---|---|---|---|
| `AUTH_INVALID_CREDENTIALS` | `errors.code.auth_invalid_credentials` | 是 | — |
| `USER_DISABLED` | `errors.code.user_disabled` | 否 | — |
| `INTERNAL_ERROR` | `errors.code.internal_error` | 是 | — |

**跳转**：成功 → `/notes`；challenge → `/login?step=new-password`；401 回跳不循环。

### 三语/暗色

- 主按钮最小宽 200，日文「ログイン」不换行；错误条限两行。
- 暗色：输入框边框对比 ≥3:1，focus 环 2px 可见；占位文字对比 ≥4.5:1。

**来源**：4.2、10；PRD P-01。**TODO**：无。登录失败不做锁定提示，限流由 Cognito 承担。

## W-02 首次设置新密码（P-02）

- **目标用户**：管理员新建/被重置的用户
- **入口**：`NEW_PASSWORD_REQUIRED` → `/login?step=new-password`
- **出口**：完成 → `/notes`；放弃 → `/login`

```
+----------------------------------------------------------------------+
| [云笺]                                                  [中|EN|日]  |
|              +--------------------------------------------+          |
|              | 设置新密码（首次登录必须修改）             |          |
|              | 新密码     [__________________________]👁   |          |
|              | 确认新密码 [__________________________]👁   |          |
|              | · 8–20 位，含大写、小写、数字              |          |
|              | [           保存并进入            ]        |          |
|              | 返回登录                                   |          |
|              +--------------------------------------------+          |
+----------------------------------------------------------------------+
```

### 区域与组件

| 区域 | 组件 | 数据来源 | 说明 |
|---|---|---|---|
| 表单 | 新密码、确认、规则清单 | Cognito 密码策略 | 规则与后台开号同源 |
| 操作 | 保存并进入、返回登录 | — | 返回丢弃 challenge |
| 反馈 | 字段级校验 + 行内错误 | `AUTH_*` | 不叠多个 toast |

### 数据字段

| 字段 | 显/编 | 来源 | 空值显示 | 三语风险 |
|---|---|---|---|---|
| 新密码 | 编辑 | 输入 | 空 | 低 |
| 规则清单 | 显示 | 策略常量 | — | 高：日文一条可能两行，预留 2 行 |
| 错误 | 显示 | `params` | 隐藏 | 中 |

### 操作

| 操作 | 触发 | 前置 | 成功后 | 失败后 |
|---|---|---|---|---|
| 提交 | 按钮/Enter | 两框非空且一致 | 拿 Token → `/notes` | 字段红字，保留输入 |
| 返回登录 | 链接 | — | 清 challenge → `/login` | — |

### 状态机

| 状态 | 显示 | 可做 |
|---|---|---|
| `idle` | 表单可用 | 输入 |
| 校验失败 | 字段级红字（长度/大小写/数字/不一致） | 改后重提 |
| `loading` | 按钮 loading，输入禁用 | 等待 |
| challenge 失效 | 「登录状态已过期，请重新登录」 | 回 W-01 |
| 成功 | 直接进主界面，无中间页 | — |

### 错误码

| code | key | 可重试 | 跳转 |
|---|---|---|---|
| `AUTH_*` | `errors.code.auth_*` | 是 | — |
| `AUTH_TOKEN_EXPIRED` | — | 重登 | `/login` |

**跳转**：成功 `/notes`；返回 `/login`；失效 `/login`。

### 三语/暗色

- 规则清单做成列表，每语言最多 3 条、每条 ≤2 行；按钮宽度 240。
- 暗色下错误红对比 ≥4.5:1。

**来源**：4.2、4.5 密码策略（v1.13.5 P-B）；PRD P-02。**TODO**：无。

| 单篇 | 彻底删除这篇笔记？ | 标题 + 原路径 + 剩余天数 + 三条不可逆说明 | 一次危险色确认 | `彻底删除` |
| 批量 | 彻底删除所选 N 篇？ | 按目录分组，每组列前 2 条 + 「另有 N 篇」；末尾知情勾选框 | 勾选后按钮才可用 | `彻底删除` |
| 整目录 | 彻底删除整个目录？ | 目录路径 + 「N 篇笔记 · M 张图片」+ 剩余天数区间 + 三条说明 | 一次危险色确认 | `彻底删除` |
| 清空 | 清空回收站？ | 总数 + 可释放容量 + 三条说明 + 确认词输入 | 输入 trim 后等于本地化确认词 | `清空` |

- **确认词本地化**：zh「清空」/ en「Empty」/ ja「空にする」，大小写与全角半角不敏感；占位文案写「输入「清空」以确认」，不写「请输入 EMPTY」这种混语言提示。
- **危险色**：主按钮用 `danger` 语义色（#C0392B 系），不写具体 hex，交由视觉稿定；次按钮为普通文本按钮，永远在左。
- **不做**：不再加第二次「确认」弹层，也不做「倒计时 5 秒后才可点」这类防误触花活——确认强度已按破坏范围分级。

### 状态机

| 状态 | 显示 | 可做 |
|---|---|---|
| `idle`（单篇/整目录） | 说明 + 可用主按钮 | 确认、取消 |
| `idle`（批量，未勾选） | 知情框未勾，主按钮禁用 | 勾选后可提交 |
| `idle`（清空，输入不符） | 输入框为空或不等于确认词，主按钮禁用 | 继续输入 |
| `submitting` | 主按钮 loading，弹层不可关（防重复提交） | 等 |
| `job_running` | 顶部一行「当前已有任务进行中（搬移/恢复/删除），完成后再试」+ 进度 | 只能取消 |
| `error` | 弹层内错误行（错误码 + 可读文案） | 重试或取消 |

### 错误码与文案

| code | HTTP | 触发 | 弹层表现 |
|---|---|---|---|
| `TRASH_PURGE_SCOPE_INVALID` | 400 | scope 与参数不匹配（如 scope=notes 却带 category_path） | 「删除范围有误，请重试」 |

### 11.3 必须覆盖的流程（10 条）

1. 登录 → 首登改密 → 进主界面
2. 新建 → 编辑 → 保存 → 412 三选一 → 继续保存
3. 共享创建 → 对方以 read 打开 → 撤销 → 对方只读 + 另存为
4. 上传图片 → 插入 → 私有图换签 → 过期重签
5. 删除 → 回收站 → 单篇恢复 / 目录恢复 job
6. **回收站多选 → 彻底删除确认（单篇/批量/目录/清空）→ job 进度 → 部分失败重试**
7. 拖拽搬移 → `JOB_RUNNING` → 完成
8. 目录导出 → 任务进度 → 下载链接过期 → 重新生成
9. **笔记设为公开（W-04a 确认）→ job 迁移 → 复制 /p/{token} → 匿名打开 → 收回私有 → 旧链接 404**
10. 管理员开号 → 用户首登改密 → 管理员禁用 → 登录被拒

### 11.4 必须覆盖的异常态（10 类）

空态（列表/搜索/共享/回收站/图片）、加载态、分页（20/50/100）、401 跳登录、403 页内错误、404、412 冲突、`JOB_RUNNING` 409、job 失败/续跑、Token 到期横幅、私有图 URL 过期重签、断网只读、**彻底删除部分成功与确认词未通过**。

### 11.5 明确不做（原型也别画）

移动端布局、实时协同光标、数学公式渲染、正文机器翻译、第四语言、自动压缩/缩略图服务端生成、**除回收站外的多选批量操作**、独立 `/error` 路由、后台删除用户、**后台代删他人回收站内容**、乐观假保存、**逐张图片的「公开/私有」开关与批量切可见性**（v1.2 取消，图片跟随笔记）、公开笔记页的评论/密码/有效期设置。回收站内的多选、批量彻底删除与清空**本期要做**，不要按旧版删掉。
