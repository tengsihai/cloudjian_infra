# 云笺 CloudJian · 项目总览

## 1. 项目介绍

云笺是一套面向 100 人以内小团队的在线 Markdown 笔记系统：打开就能写、写完能共享、删了能找回，内容可导出、不被平台锁死。仅支持 PC 浏览器，基于 AWS 全 Serverless 架构。

---

## 2. 功能一览

| 模块 | 能力 | 要点 |
|-|-|-|
| **账号** | 管理员开号、禁用/启用、重置密码、调角色 | 仅 `admin` / `user` 两档；**后台不删用户**（只禁用） |
| **登录** | SRP 登录，AccessToken 约 20 小时过期 | 业务接口只认 AccessToken；ID Token 不能调 API |
| **笔记** | 列表、新建、编辑、删除、搜索、标签 | Markdown 三模式：所见即所得 / 分屏 / 纯文本 |
| **目录** | 多级目录树、移动、重命名、删除 | 删除目录 = 整棵进回收站（后台异步执行） |
| **版本** | 自动版本历史、对比、回滚 | `edit` 可回滚；`read` 只能对比、不能回滚 |
| **回收站** | 软删除、恢复、彻底删除 | 30 天自动清理；可提前彻底删（单篇 / 批量 / 整目录 / 清空） |
| **共享** | 单篇或目录共享，`read` / `edit` | 取消共享后最长约 15 分钟收敛；编辑中被撤销 → 403 |
| **公开链接** | 笔记可设为「公开」，持链接匿名可读 | 笔记公开则里面所有图片也公开；笔记私有则图片需登录才能看，不能单独设置某张图 |
| **图床** | 粘贴 / 拖拽上传 | 公开图走 CDN；私有图走 5 分钟预签名 URL |
| **导出** | 单篇、目录 ZIP | 只能导出自己的内容；共享给我的目录不能导出 |
| **管理后台** | 开号、团队默认设置 | 「新建笔记默认可见性」「禁止公开」两个开关 |
| **多语言** | 中 / 英 / 日，切换即时生效 | 不刷新页面；语言偏好随账号同步 |

## 3. 技术架构

### 3.1 选型一览

| 层 | 选型 |
|-|-|
| 前端 | React + TypeScript + Vditor；构建 **Node.js 24 LTS** |
| 后端 | AWS Lambda（**Python 3.14**） + API Gateway **HTTP API** |
| 认证 | Amazon Cognito（SRP） |
| 存储 | S3 业务桶 + 独立 Terraform state 桶 |
| 静态分发 | CloudFront + OAC + Function（路径白名单） |
| 搜索 / 索引 | `index.parquet` + search 分片（无独立搜索引擎） |
| 定时任务 | EventBridge Scheduler → maintenance 函数 |
| 基础设施 | Terraform + GitHub Actions（OIDC，无长期密钥） |
| 部署 | 单环境 `release`（合并即上线） |

### 3.2 请求链路

```
浏览器
  ├─ 静态页面/JS   ──▶ CloudFront ──▶ Function 白名单 ──▶ S3 /web/*
  ├─ 公开图片      ──▶ CloudFront ──▶ Function 白名单 ──▶ S3 users/*/assets/public/*
  ├─ 私有图片      ──▶ S3 预签名 URL 直连（5 分钟，不经 CDN）
  └─ 业务 API      ──▶ HTTP API（JWT 授权器）
                        └─▶ Lambda（37 接口函数 + 1 维护，别名 live）──▶ S3 私有前缀
                                              │
                         EventBridge Scheduler ─┘（仅 maintenance）
```

**安全边界：** 前端**永不直读**私有 S3；私有数据只经 Lambda；CDN 只放行 `/web/*` 与公开图前缀，其余路径**一律 403 拒绝**。

### 3.3 数据怎么存（无数据库）

S3 单桶按前缀隔离：

```
cloudjian-data-tokyo/
├── web/                          # 前端静态产物
├── users/{user_uuid}/
│   ├── notes/                    # 笔记 Markdown + Frontmatter
│   ├── trash/                    # 回收站（cj:retention=30d）
│   ├── versions/                 # 版本历史（cj:retention=30d）
│   ├── shares/                   # 共享元数据
│   └── assets/                   # 图片（public/ 走 CDN，其余私有）
├── exports/                      # 导出产物（cj:retention=1d）
└── index.parquet + search/       # 索引（由笔记生成，可重建）
```

| 原则 | 说明 |
|-|-|
| 文件是真源 | Markdown + Frontmatter；索引、标签、搜索结果都由笔记生成，丢了也能重建 |
| 并发控制 | `ETag` / `If-Match` 条件写；冲突 **412 `NOTE_CONFLICT`** |
| 生命周期 | 只靠标签 `cj:retention=30d/1d`，**不用路径 prefix 规则** |
| 静态 vs 业务 | `/web/*` 与公开图走 CDN；其余对象只经 Lambda 或预签名访问 |

### 3.4 三个代码仓库

| 仓库 | 职责 |
|-|-|
| `cloudjian-frontend` | 页面、构建、发布到 `web/`、CloudFront 失效 |
| `cloudjian-backend` | 每个接口一个函数（37 个）+ 维护函数、Layer、别名、`add-permission`、业务逻辑 |
| `cloudjian-infra` | S3、CDN、Cognito、API 路由、IAM、SSM、调度、告警、流水线 |

跨仓只靠两条通道耦合：

1. **固定命名** — 如 `arn:aws:lambda:…:function:cloudjian-notes-api:live` 可推导  
2. **SSM 参数总线** `/cloudjian/*` — `api-url`、`cdn-domain`、桶名、用户池 ID 等  

### 3.5 发布模型

```
feat/* ──PR──▶ release（合并即上线）──PR──▶ main（只归档，不部署）
                 │
                 └── GitHub Environment: release + OIDC
```

| 项 | 约定 |
|-|-|
| 环境 | **只有 release**；`release` 分支即线上，`main` 只打 tag / 写发布记录 |
| 凭证 | 所有带 AWS 凭证的 CI job 必须 `environment: release` |
| 合并前检查 | 代码格式 → 配置校验 → 静态检查 → 安全扫描 → 自动化脚本检查 → 变更摘要 |
| 回滚 | revert 对应 PR 再合入 `release` |
