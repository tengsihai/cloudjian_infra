## 0. 职责边界与五条红线

### 0.1 只做 / 不做

| 只负责 | 明确不做 |
|-|-|
| S3（生命周期 / 桶策略 / OAC / CORS） | 任何 `aws_lambda_function` / `aws_lambda_layer_version` |
| CloudFront + CloudFront Function | VPC 及任何网络资源（`enable_vpc=false`，仅留空模块接线说明） |
| Cognito 池 / App Client / Groups | `s3 sync` 前端产物、CloudFront 失效执行 |
| HTTP API 路由与 Stage、JWT 授权器、网关 CORS | 改后端函数、Layer、别名、`add-permission` |
| EventBridge Scheduler（只建调度，目标为可推导 ARN） | 改前端构建与发布 |
| IAM（lambda-role、scheduler-role、3 条 GHA 角色） | 与业务代码共享代码包 |
| SSM 参数总线（`/cloudjian/*`，单一写方） | |
| 日志组、告警、Budgets、成本标签 | |
| Terraform 流水线（fmt/validate/tflint/checkov、plan 摘要、apply、漂移周检） | |

跨仓仅两条耦合通道：**固定资源命名（Lambda ARN 字符串可推导）** 与 **SSM 参数总线**。

### 0.2 五条红线（违反任一 = 阻断合入）

1. **不建 `$default` 路由**：否则 OPTIONS 被授权器拦成 401，CORS 全废。
2. **N8 单独注册为无鉴权路由**：`GET /public/notes/{public_token}` 不挂 JWT 授权器；与 `/notes/{note_id}` 路径模板必须分开注册。
3. **生命周期只用标签不用前缀**：`prefix` 是字面匹配，`users/*/trash/` 命中 0 个且不报错；只允许 `cj:retention=30d` / `1d` 两档。
4. **CDN 白名单只放两类**：`/web/*` 与 `/users/{uuid}/assets/public/*`；`assets/private/*`、`index.parquet`、`.dir_meta.json`、`users/*/notes/*` 一律 403 终态。公开笔记正文不走 CDN，只走 N8。
5. **Terraform 中不得出现 `aws_lambda_function` / `aws_lambda_layer_version`**；反向：backend 不得改桶策略/分发/Cognito/路由结构。
