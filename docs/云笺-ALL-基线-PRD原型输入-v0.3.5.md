## 1. 目标与范围

### 1.1 产品目标

面向 100 人以内团队：打开就能写、写完能共享、删了能找回。三条底线：内容可导出（不被平台锁死）、共享边界一眼可辨、单人可低成本维护。（源 1）

### 1.2 成功标准

| 级别 | 标准 | 判定 | 来源 |
|---|---|---|---|
| **P0** | 登录 → 新建 → 编辑 → 保存 → 共享 → 恢复 六步闭环无断点 | 原型走查 + 联调回归 | 2.1–2.3、6.5 |
| **P0** | 彻底删除后不可恢复：回收站、搜索、共享收件箱、图片面板、左树计数五处同时消失，直链访问返回 404 | 删除回归用例（单篇/批量/目录/清空四态） | 6.5、9.3.1 |
| **P0** | 两人同改一篇，冲突不丢数据、不静默覆盖 | 412 用例必过 | 7.5 |
| **P0** | 共享笔记里的私有图能正常渲染，撤销后不裂图、不越权 | 换签三态（200 / 403×3） | 8.1、19.5 |
| **P1** | 20 小时硬到期不导致内容丢失 | 到期 → 草稿恢复用例 | 10、T-09 |
| **P1** | 100 人规模、1000 篇以内列表与搜索稳定 | 容量与压测 | 14.1 |
| **P1** | 三语覆盖 100%，切换不刷新 | key 双向校验通过 | 9.1、9.7 |
| **P1** | 断网时不假装保存，恢复后草稿可回填 | 断网用例：只读 + 明确失败 + 恢复不丢稿 | 10、T-H |
| **P2** | 目录 ZIP 可离线还原结构 | ZIP 解压校验 | 6.6 |
| **P2** | 撤销共享后 15 分钟内对方列表不再出现 | 缓存收敛用例 | 7.2、19.4 |

### 1.3 范围

本期做：账号与登录、笔记 CRUD、多级目录 + 自由标签、Vditor 三模式、版本历史、软删除与回收站（含目录级恢复）、**回收站彻底删除（单篇 / 批量多选 / 整目录 / 清空）**、单篇/目录共享（read/edit）、**笔记公开/私有档位 + 图片跟随**、服务端搜索、单篇/批量导出、管理后台、三语与主题、会话到期保护与本地草稿。（源 2、10）

本期不做：见第 10 章。

## 2. 角色与权限

### 2.1 账号角色

| 角色 | 获得 | 能做什么 | 不能做什么 |
|---|---|---|---|
| `admin` | 管理员开通/提权 | 全部笔记能力 + 管理后台（开号、禁用/启用、重置密码、调角色）+ 团队开关 | — |
| `user` | 管理员开通 | 笔记/目录/共享/图床/导出/搜索 | 管理后台、团队开关 |
| 未登录 | — | 仅登录页 | 其他一切 |

角色由服务端账号数据判定；界面隐藏入口不等于无权。（源 4.3）

### 2.2 内容角色与共享权限

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| owner | 增删改、共享/撤销、改目录共享设置、**把本人笔记设为公开/收回私有（图片随之公开/收回）**、导出、删除、清空版本、**彻底删除本人回收站内容** | — |
| grantee（read） | 阅读、**查看版本列表并与当前版本对比** | 编辑、**回滚版本**（抽屉里不渲染该按钮）、新建子项、导出、改共享、删除、移出共享范围 |
| grantee（edit） | 阅读、编辑正文、**回滚版本**、在共享目录内**新建/编辑笔记**（自动继承权限）、**在笔记所属前缀新增图片** | 改共享设置、删根共享目录、移出共享范围、导出、删除或批量切换 owner 前缀下既有图片 |

继承：单篇共享 > 目录共享（递归）> 无；命中多处取最高（`edit` > `read`）。（源 7.3、7.4、T-02）

**彻底删除的权限边界**（v0.3.4）：只有内容所有者能在**自己的回收站**里彻底删除；`admin` 不提供「清空他人回收站」「代删」任何入口（与「后台不删用户」同一取舍）；`grantee` 看不到他人的回收站，也不存在「我删了共享笔记就替 owner 清空」的路径——软删除只进 owner 自己的 `trash/`。（源 6.5、7.4、9.3.1）

共享被撤销时（源 7.3、T-10）：

- 编辑中保存 → **403 `SHARE_REVOKED`**（不是 412），保留编辑器内容并给「另存为我的笔记」
- 只读浏览 → 15 分钟缓存到期后转只读态，提示「共享已结束」，不强制清屏
- 撤销方与被撤销方都写审计日志（CloudWatch 结构化 JSON，保留 30 天）（源 7.3、K4）

### 2.3 标签规则（源 2.2、5.3.2、T-03）

自由标签：单篇 ≤20 个、单个 ≤24 字符；无层级、无颜色、无重命名、无标签管理页，只在笔记属性面板增删。`Frontmatter.tags` 是真源，索引中的 tags 为派生。

## 3. 信息架构

```
/login ───────────── 登录 / 首次设置新密码
/notes ───────────── 主界面（未登录重定向 /login）
  ├ 左：我的笔记（目录树）｜共享给我（虚拟目录）｜回收站｜标签筛选
  ├ 中：目录列表 / 编辑器 / 搜索结果 / 回收站树
  ├ 右：图片管理抽屉｜版本历史抽屉｜笔记属性（标签/元信息）
  └ 底：语言、主题、账号菜单（改密、退出）
/admin ───────────── 管理后台（非 admin 重定向 /notes）
  ├ 用户列表｜新建用户
  └ 团队设置（新建笔记默认可见性、禁止公开）
```

- 「共享给我」的目录共享只显示**一条虚拟目录节点**，点进去展开真实子结构；单篇共享是一条独立笔记（源 7.3）
- 回收站按**原目录树**展示，不打平；每篇可恢复、可彻底删除，目录可整体恢复或整体彻底删除，顶部可多选批量删除与清空（源 6.5、9.3.1）
- 搜索结果里共享内容带「共享」徽标，路径只显示相对共享根的一段（源 6.3、T-13）

**彻底删除的产品规则（v0.3.4，源 6.5、9.3.1）**：

1. **四种粒度**：单篇、批量多选（仅笔记、≤200 篇）、整个目录（含子树）、清空回收站（全部）。目录节点不参与多选，避免「选了目录又选了子树里的笔记」导致重复计数。
2. **一律异步**：提交返回 202 + `job_id`，单篇也在任务面板可查。前端行内先显示「删除中…」并禁用该行按钮，不阻塞整页；完成后再移除行。原因：一篇笔记背后有正文对象、整目录版本历史与图片，对象数不可预估，同步接口会撞 25 秒函数超时。
3. **互斥**：同一用户同一时间只允许 1 个 purge job；purge 与 restore 互斥（会改同一批 key），冲突统一 409 `JOB_RUNNING`，带 `job_id` 与 `progress`，前端直接禁按钮。
4. **幂等**：重复提交同一 `note_id` 不报 409，已不在回收站的项进 `rejected`（`TRASH_ITEM_NOT_FOUND`），其余照常执行。
5. **不可逆提示**：确认弹层固定三行——内容不可恢复；版本历史与仅被它引用的图片会一并删除；已发出的共享关系立即失效。清空另需输入确认词，批量另需勾选知情框，单篇/目录只需一次确认按钮（危险色）。
6. **计数**：删除完成后左树「回收站 (N)」立即减 N，不等 15 分钟树缓存；缓存由服务端主动失效。

## 6. 关键流程

| 流程 | 步骤（含失败分支） | 来源 |
|---|---|---|
| 登录 / 首登改密 | 账号密码 → 若 `NEW_PASSWORD_REQUIRED` 则改密 → 拿 Token → 主界面；密码错就地报错；禁用提示联系管理员 | 4.2 |
| 会话到期 | 剩余 10 分钟单行横幅（只给「立即保存」、无续期）→ 输入停 5 秒写本地草稿（256KB 上限）→ 到期跳登录 → 重登后版本一致直接回填、不一致进差异面板 | 10、T-09、T-G |
| 断网 | 断网 → 编辑器转只读 + 顶栏「网络已断开，内容仍保存在本地草稿」→ API 动作明确失败（`NETWORK_OFFLINE`）→ 恢复后按 `base_version` 回填或走差异面板；**不做乐观假保存** | 10、T-H |
| 新建 / 编辑 / 冲突 | 新建生成 ID 与 slug → 编辑 → 带版本条件保存 → 200 成功；412 `NOTE_CONFLICT` 弹三选一；409 `DELETE_CONFLICT`；404 提示已删 | 5.2、7.5、9.4 |
| 共享创建与撤销 | 选内容 → 搜索成员（仅 active、非本人）→ 选权限 → 对方出现；撤销后 15 分钟收敛；编辑中保存得 403 `SHARE_REVOKED` → 可「另存为我的笔记」 | 7.2、7.3、T-07、T-10 |
| 图片上传 | `POST /assets/presign`（带 `note_id`，**不带可见性**，前缀由该笔记当前 `visibility` 决定；自己→自己，共享 edit→owner）→ 直传 → 登记 → 插链接；共享笔记首次插图给一行「图片存储计入笔记所有者」提示 | 8.2、K3、T-D |
| 笔记设为公开 | 笔记菜单「设为公开」→ P-26 确认 → `POST /notes/{id}/visibility` → 202 + 任务面板 → 图片迁 public、生成 `/p/{token}`、共享弹层可复制链接；收回私有 → 链接立即失效、图片迁 private | 8.1、9.3.2 |
| 私有图渲染 | 用 `asset://{id}` 占位 → `GET /assets/{id}/url?note_id=…` 换 5 分钟 URL；批量 ≤50 张走 `POST /assets/urls`；失败静默重签一次；跨前缀或未被引用一律 403 | 8.1、K2、19.5 |
| 删除 / 恢复 | 删除移入回收站并保留路径 → 树形展示 → 单篇/目录异步恢复 → 去 30 天标记 → 重名 `-1`；剩余天数按 `LastModified` 现算 | 6.5、T-04 |
| 彻底删除 | 回收站勾选或点行内「彻底删除」→ 确认弹层（范围 + 不可逆三行；清空要输「清空」、批量要勾知情框）→ `POST /trash/purge` 返回 202 + `job_id` → 任务面板看进度 → 服务端删正文对象、`versions/{note_id}/`、`assets/_trash/{asset_id}/`、`shares/*.json` 与收件箱条目 → 重建受影响搜索分片 → 索引物理移除行 → 前端移行、计数 −N、树缓存失效；失败按 `cursor` 续跑，已删对象 `DeleteObject` 幂等 | 6.5、9.3.1 |
| 目录搬移 | 发起 → 分批异步 → 整棵子树禁写（409 `JOB_RUNNING`）→ 完成后刷新索引、搜索、共享 `target_dir` → 解除只读 | 6.1、T-08、19.2 |
| 批量导出 | 选范围（单篇/目录递归/仅该层）→ 小批量同步、大批量异步 → 轮询 → 10 分钟链接；共享目录拒绝 | 6.6 |
| 管理员开号/禁用/重置 | 填资料 → 创建并初始化 → 首登改密；禁用/重置 ≤60 秒生效 | 4.5、4.7 |

## 7. 异常与边界

| 场景 | 产品表现 | 来源 |
|---|---|---|
| 空态 | 无笔记/无共享/回收站空/搜索无结果，各有独立文案与引导 | 6.2、6.3、7.3 |
| 加载态 | 列表骨架、正文骨架、图片灰块；>3 秒提示「仍在加载」 | 【新增】细化 |
| 分页 | 默认 20（可选 50/100）；标题排序用 `Intl.Collator`；搜索 `has_more` 续查；>200 条虚拟滚动 | 6.2、6.3、10、T-F |
| 无权限 | 非 admin 访问后台重定向；read 共享禁用编辑与回滚；grantee 不能导出/改共享 | 7.3、7.4 |
| 401 | 本地 `exp` 到期或服务端 401 → 清 Token 跳登录，回原深链 | 4.2、10 |
| 403 状态失效 | 禁用/降权 → 顶部提示 + 跳登录 | 4.6 |
| 403 共享撤销 | 保存返回 `SHARE_REVOKED`，保留内容、给「另存为我的笔记」，不走 412 | 7.3、T-10 |
| 412 | `NOTE_CONFLICT` + `data`（服务端内容/ETag/我的内容/diff/版本），三选一；旧版已留档 | 7.5、9.4 |
| 409 | `DELETE_CONFLICT`（并发删除）；`JOB_RUNNING`（搬移中，含 job_id/progress） | 5.3.5、6.1、9.4 |
| 404 | 笔记/目录不存在，提示已删除，给返回列表 | 5.3.5 |
| 异步 job 失败 | 显示失败项与原因，可重试/从断点续跑 | 6.1、6.5 |
| 目录搬移中 | 整棵子树禁写，按钮禁用，不「先允许再报错」 | 6.1、T-08 |
| Token 过期 | 20 小时硬过期、不续期；草稿先落本地，重登按版本决定回填或进差异面板 | 10、T-09 |
| 私有图 URL 过期 | 渲染失败静默重签一次；连续失败展示重试图标 | 8.1 |
| 上传超限 | 前端选择即校验 10MB；登记时 `HeadObject` 二次校验，超限删除并报错；文案写「上限」不写「服务端强制」 | 8.2、T-05 |

## 8. 国际化

- 三语：`zh-CN`（默认）/ `en-US` / `ja-JP`，封版不加第四种；不做语言级内容规范（源 2.6、9.1）
- 文案范围：界面、错误、管理后台、编辑器内置提示；用户正文不翻译（源 9.2、9.4、9.5）
- 统一错误信封：所有非 2xx 为 `{code, params, data?}`；412 用 `data` 携带四份数据；前端只有一条判断链（401 登录 / 403 撤销转存 / 412 差异 / 409 提示 / 其余查文案）（源 9.4、T-01）
- key 派生：`errors.code.<code 小写蛇形>`，如 `NOTE_NOT_FOUND` → `errors.code.note_not_found`；`error_codes.py` 为唯一真源，前端 key 由脚本生成，禁止手写（源 9.4、T-12）
- CI 双向校验：码表每个 code 必须有 key；语言包每个 `errors.code.*` 必须在码表登记；三语 key 集合一致（源 9.7）
- 切换即时生效、偏好随账号；日期/时区/数字按语言格式化；代码高亮与 Mermaid 关键字保持英文（源 2.6、9.3、9.5、9.6）
- 笔记 `lang` 仅作检索提示，缺失不报错、不回写（源 5.3.2、9.8）
- 到期横幅 key `common.session.expiryWarning`，中/英/日三语文案按方案给定；日英比中文长 40% 以上，横幅弹性宽度 + 单行省略，不写死像素（源 10、T-G）
- 标题与目录树排序统一 `Intl.Collator(locale)`（中文拼音、日文假名、英文忽略大小写与变音符号），全站只允许一个口径（源 9.6、9.7、T-F）

## 原型输入摘要（一页纸）

**必须覆盖的页面（25 个页面 + 1 类错误态，P-01～P-26）**：登录、首登改密、目录列表、编辑器、冲突差异面板、版本历史抽屉、图片管理抽屉、笔记属性面板、共享给我、共享设置弹层、回收站、搜索、管理后台（用户 / 团队设置）、个人设置、异步任务面板、会话到期横幅、断网提示条，以及七个补充面：新建弹层、删除确认、另存为弹层、导出参数弹层、新建用户弹层、**彻底删除确认弹层（P-25）**、**公开笔记确认弹层（P-26）**，以及页内错误态（P-24，非独立路由）。

**必须走通的流程（14 条）**：登录/首登改密、会话到期与草稿恢复、断网只读与恢复、新建+编辑+412 冲突、共享创建与撤销（403 转存）、图片上传（含首次插图归属提示）、共享笔记插图、私有图换签与越权拒绝、删除与恢复、**彻底删除（单篇/批量/目录/清空 + 失败续跑）**、目录搬移（子树禁写）、**笔记设为公开 → 匿名访问 `/p/{token}` → 收回私有链接失效**、批量导出、管理员开号/禁用/重置。

**必须画出的异常态（9 类）**：
1. 空态（无笔记/无共享/回收站空/搜索无结果）
2. 加载态（列表骨架、正文骨架、图片占位）
3. 401 跳登录、403 状态失效
4. 403 `SHARE_REVOKED`（保留内容 + 另存为我的笔记）
5. 412 `NOTE_CONFLICT`（三选一 + `data.diff`）
6. 409 `JOB_RUNNING`（搬移中整棵子树禁写）
7. 无权限（read 只渲染对比、grantee 禁导出与改共享）
8. 断网（只读 + 草稿仍在本地 + `NETWORK_OFFLINE`，不假保存）
9. 彻底删除（多选态 / 清空确认词未通过 / 部分失败可重试 / 409 `JOB_RUNNING`）
