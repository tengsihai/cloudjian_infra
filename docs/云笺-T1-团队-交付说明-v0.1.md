## 3. 必须守住的五条

1. **不建 `$default` 路由**（infra 不建路由；该红线由 **backend CI** 校验）：否则 OPTIONS 会被授权器拦成 401，CORS 全废。
2. **N8 单独 NONE**（infra 不建路由；该红线由 **backend CI** 校验）：`GET /public/notes/{public_token}` 不能挂 JWT 授权器；它和 `/notes/{note_id}` 路径模板必须分开。
3. **生命周期用标签不用前缀**：`prefix` 是字面匹配，`users/*/trash/` 命中 0 个且不报错；只允许 `cj:retention=30d/1d`。
4. **CDN 白名单只放两类**：`/web/*` 与 `/users/{uuid}/assets/public/*`；`assets/private/*` 与 `index.parquet`、`.dir_meta.json` 一律 403 终态。公开笔记正文**不走 CDN**，只走 N8。
5. **Terraform 里不得出现 `aws_lambda_function` / `aws_lambda_layer_version`**；反过来后端也不得改桶策略/分发/Cognito。

## 5. 验收门禁（缺一条不算交付）

- 4 类造数（Copy 进 trash、versions、exports、普通笔记）逐個 `get-object-tagging` 有标签，`list-objects-v2` 命中 >0；8 天后非当前版本 ≤3；31 天后 trash/versions 清空。
- Function 行为矩阵全绿：`/web/*` 200、公开图 200、私有路径 403、未知路径 rewrite index、缺失静态文件 404。
- API 壳齐：`verify_apigw_shell.sh` 通过（无 route/integration、无 `$default`、JWT/CORS 配置正确）；路由红线由 backend CI 校验（N8 = NONE 等）。
- OPTIONS 预检 200；401 响应带 CORS 头（与 T3 联测）。
- `terraform plan` 无漂移；`checkov` 无高危；GHA 角色只能被对应仓库 assume。

## 6. 常见坑（前人踩过）

- 给 Copy 进 `trash/` 时忘了 `TaggingDirective=REPLACE` → 旧标签残留或丢失 30 天标签。
- 桶策略写成 `bucket/*` → 越权面过大，CI 会拦。
- CDN 缓存未把 `Origin` 进缓存键 → 首个无 Origin 响应把"无 ACAO"缓存住，canvas 缩略图间歇失败。
- 把 `assets/private/*` 交给 CloudFront"挡"而不是"无入口" → 一旦 Function 写错就泄露。
- Cognito 配"8–20 位"时找不到最大长度字段 → 20 位上限只能前端 + Lambda 保证（合同见契约 §3 `PASSWORD_POLICY`）。
